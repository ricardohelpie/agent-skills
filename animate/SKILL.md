# Animation Implementation Skill

1. Ask user for: animation type (slide-in, fade, parallax, reveal), direction, duration, trigger (scroll/hover/load)
2. Confirm understanding before writing any code
3. Implement in pure CSS where possible, JS only if scroll-driven
4. Test by describing the expected visual behavior back to the user
